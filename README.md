# 📚 Library Management System

A simple **Library Management System** developed using **HTML** for the Web Technology Laboratory. This project demonstrates the basic concepts of HTML by creating a single-page library management website with navigation, forms, tables, images, and scrolling effects.

---

## 🌐 Live Demo

🔗 https://mohanashankar2007-spec.github.io/Library-Management-System/

---

## 📖 About the Project

The Library Management System is designed to provide a simple interface for managing library activities. It includes sections for adding books, searching books, issuing books, returning books, and viewing contact information.

The project is developed using **HTML only** without CSS or JavaScript, making it suitable for beginners and academic laboratory exercises.

---

## ✨ Features

- 🏠 Home Page
- 📖 Add Book Section
- 🔍 Search Book Section
- 📚 Book List
- 📕 Issue Book
- 📗 Return Book
- 📞 Contact Information
- 🖼️ Scrolling Library Image using `<marquee>`
- 📋 Navigation Menu
- 📝 Forms for Library Operations
- 📊 Book Details Table
